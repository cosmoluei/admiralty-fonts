# Changelog — Admiralty Font Family

All notable pre-release milestones (`0.x` design track) are documented here. All releases use **SIL Open Font License 1.1** (without Reserved Font Name).

---

## `[0.600]` — 2026-11-22

- Sans, Serif and Mono use the same upright punctuation drawings and advances in both styles at each weight. Width and corner radius preserve those drawings, including case-sensitive punctuation and both halves of Mono programming ligatures.
- Full stops and the detached dots in colons, semicolons, ellipses, exclamation marks and question marks are circular throughout the design space.
- Adjusted spacing around upright punctuation, including repeated Thin dashes and italic letters next to brackets or quotes. Mono keeps its 600-unit cells.
- The web package loads each italic face as one variable font so spacing also works between extended Latin letters and punctuation. The glyph reviewer and the family proof include the updated fonts.

---

## `[0.500]` — 2026-11-20

- Added 29 interface symbols for messaging, device control, permissions and travel, bringing the catalog to 311. The new symbols occupy U+E11A through U+E136. Existing names and code points are preserved.
- Added the aliases `globe`, `pause-filled` and `phone-off` to the platform packages and refreshed the website gallery and downloadable fonts.
- Refined zero-radius letterforms in the full-range fonts and added regression checks and review specimens.

---

## `[0.400]` — 2026-11-19 (full-range edition and website)

- **Full-range variable fonts** for Sans, Serif, Mono (each with italic) and Symbols: weight 100–900, width 65–150% and corner radius `RADI` 0–100, in `fonts/variable/fullrange/`, with their build tools, audits and proofs in `scripts/fullrange/`. Sans and Serif keep the same letter widths at every setting.
- **Website** in `site/`: a one-page specimen with a draggable hero, the Serif/Sans divider, a workbench of six interfaces, the symbols and the character set. It uses the full-range fonts and is published to GitHub Pages by `.github/workflows/pages.yml`.
- Version 0.400 in every font and package. Names and code points of existing symbols are unchanged.

## `[0.300]` — 2026-11-16 (Review 2 refinement, rounds 1–4)

- **New characters** (added to 0.300 before it is tagged):
  - **64 new symbols** (`U+E0DA`–`U+E119`, 282 in all): devices (computer, laptop, phone, tablet, watch, devices, browser), agent and tools (brain, web search, deep research, project, artifact, summarize, translate, computer use, screen share, extension, API, server), chat, account and billing (usage, appearance, billing, receipt, wallet, subscription, Face ID, fingerprint, QR code, scan), time and places, media and voice, charts, mail and contacts, drag handle, heart, bug, and filled `heart-filled` and `play-filled`. Seven are mirrored in RTL. Source: `scripts/symbols_phase2.py`.
  - **Google Fonts Latin Plus** in Sans, Serif and Mono, every style: superscripts and subscripts, `⅓ ⅔ ⁄`, 17 more currency signs, `ℓ ℮ Ⓓ ∂ ∅ ∏ ∑ ∫ ‖ ⟨ ⟩`, `↖ ↙ ↕` and the geometric shapes. Source: `scripts/glyphs_latin_plus.py`.
  - **Vietnamese**: `Ơ ơ Ư ư`, the marks hook above, dot below and horn (with mark anchors), and all precomposed letters `U+1EA0`–`U+1EF9`, built from components. Acute, grave and hook sit beside a circumflex; caps stacks stay under the 980 ascent. New letters share their base letter's kerning. Source: `scripts/glyphs_vietnamese.py`.
  - **Mono box drawing and block elements** (`U+2500`–`U+259F`, 160 characters) that join across the full cell height, upright in the italics. Source: `scripts/glyphs_box.py`.
  - **After the owner's review**: `browser` is now a compass, `edit-message` has a larger pencil, `schedule-send` a clearer clock, `usage` a plain gauge with a needle, `artifact` a triangle, circle and square (no frame, so it no longer looks like `image`), `brain` is seen from above with two halves; `command` (⌘) joins its square to the loops; `₴` no longer has gaps where the bars cross; superscripts, subscripts and the fractions `¹ ² ³ ⁴–⁹ ₁–₉ ½ ¼ ¾ ⅓ ⅔ ⁄` are drawn the same way in every weight, so they keep their size and do not break in the variable fonts; `₨` and `deep-research` no longer break between weights.
  - `specimens/review.html` (`scripts/build_review.py`) for reviewing these additions.
- **Packages for apps** (in `packages/`, generated by `scripts/build_native_packages.py`):
  - iOS Swift package **Admiralty** (`Package.swift` at the top of the repository): all 21 static fonts, `Font.admiralty(.serif, size:)`, `UIFont.admiralty`, `AdmiraltyIcon("heart-filled")`, `Text(admiralty:)`, `Image(admiralty:)`, `UIImage.admiralty(_:)`.
  - Android library module **admiralty**: text fonts with `<font-family>` XML, 282 vector drawables, `AdmiraltySymbol` and `AdmiraltyFonts`.
  - Flutter package **admiralty**: all fonts, `AdmiraltyFonts`, `AdmiraltyIcons` (with `named()`).
  - Web: `admiralty-fonts.css` and `admiralty-symbols.css` (`<i class="adm-icon adm-heart-filled">`).
- **`AGENTS.md`** (and `CLAUDE.md`): a guide for coding agents that use the fonts in an app.
- **Web fix**: the web font subsets left out about 70 characters (233 in Mono), such as the spacing accents, combining marks, superscripts, box drawing and geometric shapes. The ranges now come from each font's own character map.
- **Release preparation, part 2**:
  - Static TTF files are hinted with ttfautohint (clearer small text on Windows). Scaled or flipped components are drawn as outlines first, and the integer-ppem flag is set. WOFF2 files and variable fonts stay unhinted.
  - `symbols/svg/` now holds plain filled outlines taken from the fonts, with `fill="currentColor"`. The old files used strokes with `<mask>` cut-outs, which Flutter (flutter_svg), Android Studio's SVG import and some design tools draw wrongly. The web sprite uses the same outlines.
  - Flutter: the icon for `new` is now `AdmiraltyIcons.newIcon`, because `new` is a reserved word in Dart.
  - The name stays *Admiralty* (decided by the owner); no Reserved Font Name.
- **Release preparation**: `æ` in the italics has its own straight a-stem with an open notch before the e (it read as `œ`); Mono `æ` redrawn as one outline (no notch at the bottom); SemiBold 600 instances in the designspace files; `gftools builder` configs in `sources/`; Google Fonts descriptions in `documentation/`; `AUTHORS.txt`, `CONTRIBUTORS.txt`, `requirements.txt`; README, usage guide, QA report and tokens updated for 0.300; copyright URL `https://github.com/cosmoluei/admiralty-fonts`.
- **Round 4**: Serif `a` tail and `g` joins; italic exit hooks in all weights; Serif Italic `k`; straight prime marks in Medium/Bold; `i-ogonek` soft-dotted; `Qj` and other kerns; OTF hinting (needs AFDKO); one copyright line in the fonts and `OFL.txt`; `legal` symbol redrawn; a clean-up pass for tiny segments on every glyph. Details in `review2/REVIEW2_CHANGES.md`.

The notes below are from rounds 1–3.

Made from the findings of Review 2 and the owner's notes on the symbols.

- **Symbols**: 48 symbols redrawn in `scripts/symbols_refine_r2.py` (overrides the old drawings, which stay in `symbols_phase1_*.py`): correct arrow heads (`retry`, `regenerate`, `sync`, `restore`, `history`, `reply`, `forward-message`), one shared cloud for the whole cloud family, clearer `dark-mode`, `theme`, `tool`, `data-controls`, `tabs`, `timeout`, `advanced-search`, `help-center`, `legal`, `toggle-on/off`, `plan`, `mention`, `attach`, `pdf`, `share-app`, `new`, `settings`, `import/export`; `online/offline` share one drawing; filled variants are now the outline drawing plus fill.
- **Symbols size**: drawing scale 1.2× (`GRID_SCALE = 36`), so a typical symbol is about cap height (676 of 700 units) and strokes are 72 / 85 / 101 units (were 60 / 70 / 84).
- **Symbols metadata**: `label` (accessibility text) and `glyphName` added to `admiralty-symbols.json`; glyph names use `_` instead of `-`.
- **Medium / Bold / italics**: new join rules and curve fitting in `bolden_contours_smooth` (`glyphs_bold.py`): no dents at the top and bottom of round letters, stems no longer taper. Mono `K` joint fixed.
- **Serif Bold**: `A V W Y v w y` rebuilt with parallel stroke walls, so the diagonals carry the same weight as the upright stems.
- **Kerning** (same in Sans and Serif): positive pairs for `f` + tall letters and capitals, `j` after brackets, `qj`, `jj`, doubled `V W Y v w y`.
- **Variable fonts**: masters are now aligned by splitting segments (`scripts/vf_align.py`) instead of re-drawing outlines, so the variable fonts at 400 / 500 / 700 match the static fonts. `STAT` uses exact values, a SemiBold 600 named instance and name ID 25 were added.
- **Symbols, round 3**: `help`, `timeout`, `history`, `restore`, `cloud-off`, `link`, `unlink`, `automation`, `background-task`, `tabs` redrawn after owner feedback; `specimens/inspector.html` rebuilt.

## `[0.200]` — 2026-11-17 (Milestone 8: Variable Fonts, Final QA & 5-Platform Delivery)

- **7 Variable Fonts (`wght 400..700`)**: Compiled `AdmiraltySans[wght]`, `AdmiraltySans-Italic[wght]`, `AdmiraltySerif[wght]`, `AdmiraltySerif-Italic[wght]`, `AdmiraltyMono[wght]`, `AdmiraltyMono-Italic[wght]`, and `AdmiraltySymbols[wght]` (TTF + WOFF2) with canonical `STAT`, `fvar`, `gvar`, `HVAR`, `gasp` (`0x000F`), and `prep` tables.
- **Corner- & Extremum-Locked Contour Harmonizer** (`scripts/build_variable.py`): Aligned contour order, winding, sharp corners, and X/Y extrema across all 21 UFO masters (`Regular 400`, `Medium 500`, `Bold 700`) so non-master weights (`435`, `450`, `525`, `600`, `640`) interpolate cleanly without kinks or self-intersections (`0.0u` Sans vs Serif duplex advance parity across `wght 400..700`).
- **Symbols Variable `GSUB rvrn`**: Added smooth contour-count topology switching (`rvrn` + mirrored `rtlm`) across weights `450–700` for the 27 symbol icons whose stroke dilation merges or splits paths.
- **5-Platform Delivery (`dist/`)**: Generated platform packages for `apple-ios-macos`, `android` (218 VectorDrawables + XML font families), `windows`, `web` (Unicode-range Variable WOFF2 subsets + CLS-zero CSS + SVG sprite), and `cross-platform` (Flutter `IconData` Dart map + JSON).
- **Documentation & QA**: Delivered `docs/USAGE_GUIDE.md`, `tokens/admiralty-design-tokens.json`, `docs/QA_AND_ORIGINALITY_REPORT.md`, `specimens/Admiralty_Type_Review_Proof_v0.200.pdf`, and upgraded `specimens/inspector.html` with a live continuous `wght 400–700` slider.

# Admiralty

**Version 0.300 — test release.** The design is still being reviewed and may change before 1.000.

Admiralty is a font family made for a personal agent app: a calm, professional look that stays comfortable over long use. It has four families:

| Family | What it is for |
| --- | --- |
| **Admiralty Sans** | A humanist sans serif for interface text and the user's messages. |
| **Admiralty Serif** | A low-contrast text serif for the agent's messages. It has the same letter widths and kerning as Sans in every weight, so switching between the two never changes line breaks. |
| **Admiralty Mono** | A monospaced companion for code, logs and IDs (every character is 600 units wide). Optional programming ligatures are in `ss01`. |
| **Admiralty Symbols** | 282 interface icons on a 24 × 24 grid in the Private Use Area (`U+E000`–`U+E119`), drawn to sit at cap height next to the text. |

Sans, Serif and Mono each have six static styles (Regular, Medium, Bold and their italics) and two variable fonts (`wght` 400–700, with named Regular, Medium, SemiBold and Bold). Symbols has Regular, Medium and Bold and one variable font. The text families cover the Google Fonts Latin Core and Latin Plus sets, Latin Extended-A, Pinyin and Vietnamese. Mono also has the box drawing and block characters (`U+2500`–`U+259F`) for terminal interfaces.

## Using the fonts

Ready-to-use font files are in [`fonts/`](fonts):

- `fonts/variable/` — variable fonts (`.ttf` and `.woff2`), best for apps and the web
- `fonts/ttf/`, `fonts/otf/`, `fonts/woff2/` — static styles

Icons are also available as SVG files in [`symbols/svg/`](symbols/svg), with names and accessibility labels in [`symbols/admiralty-symbols.json`](symbols/admiralty-symbols.json).

Open [`specimens/inspector.html`](specimens/inspector.html) in a browser to try every style, the weight axis, the icons and the kerning. The page loads its styling from the internet. [`specimens/review.html`](specimens/review.html) shows the 0.300 additions: the new symbols, Latin Plus, box drawing and Vietnamese.

### In apps

Ready-made packages are in [`packages/`](packages), for iOS (Swift package, added from this repository's URL), Android (library module), Flutter and the web. They use the fonts and the symbols by name, much like SF Symbols:

```swift
Text(reply).font(.admiralty(.serif, size: 17))
AdmiraltyIcon("heart-filled")
```

**Coding agents:** start with [`AGENTS.md`](AGENTS.md). It lists every file, the rules (symbol names, weights, accessibility, right-to-left, CJK fallbacks) and a recipe for each platform.

The [usage guide](docs/USAGE_GUIDE.md) covers sizes, weights, CSS, iOS, Android and Windows examples, and fallback fonts for Chinese. Design tokens are in [`tokens/admiralty-design-tokens.json`](tokens/admiralty-design-tokens.json).

## Building

The fonts are generated by Python scripts; the scripts are the true source of the design.

```bash
pip install -r requirements.txt

python3 scripts/build_fonts.py       # all static and variable fonts, symbols, UFO sources and designspaces
python3 scripts/build_delivery.py    # platform packages in dist/ (Apple, Android, Windows, web, cross-platform)
python3 scripts/audit_qa.py          # checks -> docs/QA_AND_ORIGINALITY_REPORT.md
python3 scripts/build_inspector.py   # specimens/inspector.html
python3 scripts/build_review.py      # specimens/review.html
```

`build_fonts.py` takes about two minutes. If AFDKO is installed (`pip install afdko`), the OTF files are hinted; if ttfautohint is installed (`pip install ttfautohint-py`), the static TTF files are hinted. The WOFF2 files and the variable fonts stay unhinted.

### Google Fonts build

The UFO masters and designspace files in [`sources/`](sources) are written by `build_fonts.py`. Sans, Serif and Mono can also be built from them with the Google Fonts tool chain:

```bash
pip install gftools
cd sources
gftools builder config-sans.yaml     # also config-serif.yaml and config-mono.yaml; output in build/gf/
```

These builds have the same outlines and spacing as `build_fonts.py`. Descriptions for the Google Fonts pages are in [`documentation/`](documentation). Admiralty Symbols is not meant for Google Fonts, because it only uses Private Use Area code points.
